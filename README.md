# About this Game

**What is the game about?**

The purpose of the trading game is to increase the capital of the players so that the player with the highest amount wins the game. You can play with 1-4 players. If a single player plays, then you play again a GenAI chatbot or by using our browser-based game. 

You can pick any currency pair, but we will start with Yen/US Dollar. If you choose other currency pairs, modify the event cards to reflect names and details of different countries.
